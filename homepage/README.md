# LITRIT homepage (starting point)

Source for the LITRIT homepage draft, created as a Claude Design canvas.

- `project/Main.dc.html`: the homepage artboard. Two top tabs switch between the
  SparkSale page (small retailers) and the AI Capability Building page (enterprises).
- `project/canvas.json`: canvas layout for the artboard.
- `logo.png`: LITRIT logo, used in the header and footer.

The live draft is at https://claude.ai/artifact/4fVwkBJ4Rd8kUbzmbF8NFi. The file in
`project/` is a copy of that draft, so edit here and republish to the artifact, or
convert it into a standalone site later.

Open items before launch: placeholders such as `[+x%]`, the MK Optics quote, FAQ
answers, and the logo path (`/_blob/...` in the Design version; point it at `logo.png`
for a standalone site).
